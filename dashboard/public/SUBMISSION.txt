How does this project use Squeekchain?

Squeektoshi Live is a community dashboard that answers one question: is Squeektoshi on the wheel right now? Every 15s it reads Squeekchain's public API (/v1/status and /v1/economy/state) for live WHEELY9000 telemetry (core status, RPM, rim speed) plus the chain state: cumulative work, Squeek block height and progress, difficulty (work per 1k blocks), settlement round and SQK minted against the cap. If the API is down it reads SqueekCore.state() and SqueekToken.totalSupply() directly over Sepolia RPC. It links the X livestream, and an optional "Ping SQK" button lets a visitor send a harmless approve(self, 0) to the SQK token on Sepolia from their own wallet.
